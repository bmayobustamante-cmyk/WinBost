# WinBoost

**Proyecto independiente de optimización de Windows para gaming.**

WinBoost busca facilitar la gestión de opciones de Windows relacionadas con el rendimiento y la experiencia de juego, con especial atención a la seguridad, el control del usuario y la reversibilidad de los cambios.

## Estado del proyecto

🚧 **Versión 0.3 — Experimental**

WinBoost está en desarrollo. La versión actual necesita validación en equipos Windows reales antes de poder confirmar su estabilidad, compatibilidad y efectos sobre el rendimiento.

## Objetivos

- Facilitar la gestión de opciones relacionadas con el gaming.
- Priorizar cambios controlados y reversibles.
- Mostrar información útil sobre el estado del sistema.
- Permitir analizar mediciones de rendimiento.
- Evitar promesas de mejora de FPS que no estén respaldadas por pruebas reproducibles.

## Pruebas y rendimiento

Todavía no se publican cifras verificadas de mejora de FPS.

Las futuras evaluaciones deberían comparar los mismos juegos, escenas, ajustes gráficos y condiciones, registrando los resultados antes y después de cada cambio.

## Seguridad

La seguridad del sistema es una prioridad.

- No se recomienda desactivar las protecciones de seguridad de Windows para ejecutar WinBoost.
- Los cambios del sistema deben explicarse antes de aplicarse.
- Las funciones experimentales deben probarse con precaución.
- La compatibilidad y la reversibilidad deben verificarse en Windows.

## Desarrollo

WinBoost es un proyecto independiente en evolución. Las funciones, la compatibilidad y los requisitos pueden cambiar durante su desarrollo.

## Próximos hitos

1. Revisar técnicamente la versión 0.3.
2. Validar su funcionamiento en Windows.
3. Comprobar que los cambios se pueden revertir correctamente.
4. Realizar pruebas de rendimiento reproducibles.
5. Documentar los resultados, incluidos los negativos.

## Aviso

WinBoost no garantiza un aumento de FPS ni mejoras en todos los equipos. Los resultados pueden variar según el hardware, el juego, los controladores y la configuración del sistema.
